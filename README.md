# 🚀 CareerHub — Full Stack MERN Job Portal

CareerHub is a modern, scalable, and feature-rich Job Portal Web Application developed using the MERN Stack (MongoDB, Express.js, React.js, Node.js).

The platform connects Job Seekers and Recruiters through a seamless digital recruitment experience with secure authentication, smart job management, resume uploads, and a responsive modern UI.

The application allows users to search and apply for jobs, manage profiles, upload resumes, and track applications, while recruiters can create companies, post jobs, and manage applicants through a dedicated dashboard.

# ⚙️ Installation & Setup

## Clone Repository

```bash
git clone https://github.com/your-username/careerhub.git
cd careerhub
```

---

# 📦 Install Dependencies

## Backend Setup

```bash
cd backend
npm install
```

## Frontend Setup

```bash
cd frontend
npm install
```

---

# 🔑 Environment Variables

Create a `.env` file inside the `backend` folder and add:

```env
MONGO_URI=

PORT=

SECRET_KEY=

CLOUD_NAME=

API_KEY=

API_SECRET=
```

---

# ▶️ Run the Project

## Start Backend

```bash
cd backend
npm run dev
```

## Start Frontend

```bash
cd frontend
npm run dev
```
